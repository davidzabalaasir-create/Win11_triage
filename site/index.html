¿Tu Windows tiene algo raro?
Descúbrelo en minutos.

win11-triage revisa lo que arranca solo, los procesos, la red, los eventos y las extensiones del navegador. Puntúa cada elemento de 0 a 100, explica por qué y te dice qué hacer. Gratis, de código abierto y solo lectura.

⬇ Descargar para Windows 11 Ver el código

Qué revisa

Los mismos sitios que mira un analista de respuesta a incidentes, en un solo análisis.

--autoruns

Persistencia

Programas, servicios, tareas, WMI e IFEO que arrancan solos, con Autoruns de Sysinternals.

--processes

Procesos y árbol

Rutas raras, nombres de sistema suplantados, Office lanzando consolas y la cadena completa de padres.

--sigma

Reglas Sigma y Sysmon

Motor Sigma propio sobre Sysmon, 4688, PowerShell 4104 y 7045. Añade tus reglas en una carpeta.

--browsers

Extensiones

Chrome, Edge, Brave y Firefox: extensiones fuera de la tienda, sin firma o con permisos peligrosos.

--vt · --intel

Reputación

VirusTotal para hashes, AbuseIPDB para IPs y MalwareBazaar para malware conocido. Con caché.

--static

Contenido

Análisis PE (empaquetadores, imports de inyección) y reglas YARA, sin ejecutar nada.

--remote

Otros equipos

Triaje remoto por WinRM sin instalar nada en el equipo analizado.

--schedule

Vigilancia programada

Análisis diario o semanal que solo avisa si aparece algo nuevo o peor: notificación, Slack, Teams, Splunk o Wazuh.

Cómo funciona

Señales explicables en lugar de una caja negra.

Recoge

Lee el estado del equipo sin modificarlo: nunca borra, termina procesos ni sube ficheros.

Puntúa

Cada señal suma o resta puntos y se asocia a una técnica de MITRE ATT&CK.

≥ 70 Detectado30–69 RevisarLimpio

Te guía

«¿Qué hago con esto?» con pasos concretos, revisión de analista, comparación entre análisis y paquete de evidencias.

Informes para cada público

HTML autocontenido y Markdown para el técnico, JSON y JSON Lines para el SIEM, CSV para Excel y un resumen ejecutivo en PDF de una página para quien tiene que decidir.

Descargar

Instalador, MSI para empresas o versión portable. También desde el código con Python 3.10+.

⬇ Última versión 
git clone https://github.com/davidzabalaasir-create/Win11_triage.git
cd Win11_triage
pip install .
win11-triage --gui                 # interfaz gráfica
win11-triage --all --format all    # todo, desde la consola
win11-triage --dry-run --explain   # demostración con datos de ejemplo

Los ejecutables van firmados con un certificado propio («David»). Windows SmartScreen o el Control inteligente de aplicaciones pueden avisar porque no es un certificado comercial; si lo bloquea, usa la versión desde el código (Python).
